Smart List View Pro

Save personal list layouts and publish team presets without modifying business records.

Choose which columns a list shows, in which order and at which width — then save it as a named layout you can apply in one click. Administrators can share a layout with the whole team. Layouts only change what you see: no record, view or access right is modified.

Odoo 19 Community & Enterprise · self-hosted or Odoo.sh · not available on Odoo Online

What you can do

  • Show or hide columns the list already offers you.
  • Reorder columns with keyboard-friendly up/down buttons.
  • Set column widths from 80 to 600 px, or leave them automatic.
  • Save as new layout, save changes, rename, duplicate and delete.
  • Shared layouts: administrators publish a layout for all internal users and unpublish it again.
  • Reset returns to the standard Odoo columns at any time — saved layouts are kept.
  • One list at a time: a layout belongs to the list (model, view and menu action) it was saved on.
  • Native list kept: sorting, filters, grouping, pager, selection and editing work as before.

Arrange the columns of the list you are on

The Layouts button sits next to the list's own controls. The panel lists the columns the current view shows you, with their visibility, order and width.

See every change live

Changes apply to the list immediately and are marked as Unsaved layout changes until you save them. Nothing is stored before you choose to.

Save it under a name

Personal and shared layouts

My layouts are private to you. Layout administrators can publish one to Shared layouts for every internal user of that list.

Team members apply shared layouts

Other users can apply a shared layout or duplicate it into their own layouts, but cannot change or remove it.

Permissions

User Own layouts Shared layouts Publish / unpublish
Internal user Create, apply, rename, duplicate, delete Apply, duplicate as own No
Smart List Layouts Administrator (included in Settings administrators) Create, apply, rename, duplicate, delete Apply, rename, update, unpublish Yes
Portal and public users No access

All checks run on the server, including direct API calls. A layout only ever contains columns of the list it was saved on; columns a user is not allowed to read are never shown to them, and a duplicated layout keeps only the columns the copying user may read.

Good to know

  • Available on list views opened from a menu or action. Not shown in lists inside dialogs, one2many/many2many sub-lists or embedded lists.
  • Columns with buttons, special widgets, the drag handle, properties, and columns hidden by the view's own conditions stay under Odoo's control.
  • Columns cannot be edited while the list is grouped; remove the grouping first.
  • A layout is applied when you choose it. It is not re-applied automatically after a page reload.
  • If the view changes later, removed columns are skipped with a warning.

Technical

  • Depends only on base and web.
  • No external service, no tracking, no data leaves your database.
  • Layouts are stored in a single model (smart.list.preset) with record rules; uninstalling the module removes them and leaves your records untouched.
  • Tested on Contacts, CRM and Sales lists of Odoo 19 Enterprise.
